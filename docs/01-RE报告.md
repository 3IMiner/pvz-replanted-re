# 《PvZ Replanted》逆向（RE）报告

> 目标：`PVZ Replanted`（Unity 6000.0.52 / IL2CPP / x86-64）
> 工具：UnityPy 1.25.4（资源/序列化数据）、MelonLoader interop（符号）、Harmony（运行时验证）
> 产出数据：`re\data\plants.json`、`zombies.json`、`levels.json`

---

## 1. 结论先给

RE 做得到：

- ✅ 类型的完整符号（823 个类、全部方法/字段签名）
- ✅ 全部游戏数值：**80 个植物定义、37 个僵尸定义、151 个关卡定义**（含 cost、recharge、血量、首现关卡、权重）
- ✅ 全部美术/音频资源（Addressables bundle 可直接读出）
- ✅ 运行时行为验证（Harmony 补丁直接调 `Board.AddPlant` / `AddZombieAtCell`）

RE 做不到：

- ❌ 把这份 x64 构建变成 Android 构建。理由见第 5 节。

## 4. 这些数据用在哪了

已经接进原生重制版（`native\web\game.js`）：

- 植物 cost / 冷却改成真实值：向日葵 50/7.5s（25s 产阳光）、豌豆 100/7.5s、寒冰射手 175/7.5s、坚果 50/30s、樱桃 150/50s、辣椒 125/50s、双发 200/7.5s
- 僵尸血量改真实值：普通 200、路障 200+360=560、铁桶 200+1100=1300、新增橄榄球 1600
- 新增**寒冰射手**（命中减速 50% / 3 秒）和**火爆辣椒**（整行 1800 伤害）

也就是说：RE 拿到的不是"看看而已"的资料，而是直接驱动了重制版的数值层。

## 5. 为什么 RE 也变不出 Android 版

| 环节 | RE 能给什么 | 能否用于重编 |
|---|---|---|
| C# 代码 | IL2CPP 已编译成 x86-64 机器码；Cpp2IL/Il2CppDumper 只能给出伪代码 + 元数据 | ❌ 不能直接编译；反编译体缺失/失真 |
| Unity 工程 | **不存在**。没有 `.unity`、没有 prefab 引用、没有 Addressables group 配置 | ❌ 无法 Build Target = Android |
| 场景与预制体 | 序列化数据在 `.assets`/bundle 里，可读出对象与字段 | ⚠️ 能读，但脚本 GUID 指向已编译脚本，重编后全部断链 |
| 资源 | 贴图/音频/Spine 都能导出 | ⚠️ 能用，但需要重做材质、shader、动画状态机 |
| Shader | D3D11 编译的字节码 | ❌ Android 需要重新编译成 GLES/Vulkan |
| IL2CPP 运行时 | `GameAssembly.dll` 是平台原生库 | ❌ 需 NDK + 原 C++ 中间代码，无法从 x64 二进制反向生成 |

**一句话**：RE 能还原"这个游戏怎么运转"和"它用什么数字/资源"，但还原不出"可以用 Unity 重新编译这个游戏的工程"。任何号称能一键 IL2CPP→APK 的工具，要么是模拟器容器，要么是重做。

## 6. 复现步骤

```powershell
# 1. 安装 UnityPy（如果 pip 报 ProxyError，先设对代理协议）
$env:HTTP_PROXY='http://127.0.0.1:7890'; $env:HTTPS_PROXY='http://127.0.0.1:7890'
python -m pip install UnityPy attrs Pillow
# 注意：attrs 需 >= 21.3（旧版没有 attrs.define）

# 2. 读 bundle 里的定义（typetree）
python re\dump_defs.py     # 输出 re\data\*.json
```

bundle 位置：`PVZ Replanted\Replanted_Data\StreamingAssets\aa\StandaloneWindows64\`
- `defaultlocalgroup_assets_plantdefinitiondata_*.bundle`
- `defaultlocalgroup_assets_zombiedefinitiondata_*.bundle`
- `defaultlocalgroup_assets_leveldata_*.bundle`

> 所有 bundle 都保留了 type tree（字段名可读），这是能直接 dump 数值的前提。
