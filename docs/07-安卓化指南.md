# 把《植物大战僵尸：重植版》PC 版搬到安卓上 —— 可行方案（2026-11）

> 对象：`./PVZ Replanted`（1.65 GB，137 个文件，Unity 6000.0.52f1 / IL2CPP / x86-64）

---

## 0. 一句话结论

这个文件夹里**没有任何"可以转成 APK"的原料**，它只是一份已经编译好的 Windows x64 游戏。

- ❌ **不存在**任何工具能把 `Replanted.exe` + `Replanted_Data` 直接变成能装的 APK。这不是"找对工具"的问题，是架构问题。
- ✅ 真正能跑的办法只有两类：**在安卓上跑 Windows 版**（Winlator 11.x / 盖世游戏），或**把画面串流到手机**（Sunshine + Moonlight）。
- ℹ️ 官方也**没有安卓版**：EA 只给了 iPhone 的 Apple Arcade 版（2026 年 12 月），并明确表示 Android 不在计划内，所以"等官方 APK"这条路也堵死了。

---

## 1. 这个包到底是什么（实测清单）

| 文件 / 目录 | 大小 | 作用 | 架构 |
|---|---|---|---|
| `Replanted.exe` | 676 KB | Unity 启动器，版本 1.5.1468 | **x64** |
| `GameAssembly.dll` | 87 MB | IL2CPP 编译后的**全部游戏逻辑**（C# 已变成机器码） | **x64** |
| `UnityPlayer.dll` | 33 MB | Unity 6 运行时（含 58 处 AVX/VEX.256 指令） | **x64** |
| `baselib.dll` | 228 KB | Unity 基础库 | x64 |
| `Replanted_Data/` | 1.52 GB | 场景、贴图、音频、Addressables 资源 | 平台化 |
| `Replanted_Data/StreamingAssets/aa/StandaloneWindows64/` | ~1.4 GB | Addressables 资源束，**平台名写死为 Windows** | D3D11 shader |
| `Replanted_Data/il2cpp_data/Metadata/global-metadata.dat` | 18 MB | IL2CPP 元数据（只有描述，没有可编译的源码） | — |
| `Replanted_Data/Plugins/x86_64/steam_api64.dll` + `steam_emu.ini` | 1 MB | **免 Steam 运行**（RUNE 版，AppId 1903340） | x64 |
| `Replanted_dxgi.log` | 992 B | 旧日志：DXVK **1.10.3-async**，`Failed to create Vulkan 1.1 instance` | — |

> 后两条很关键：**免 Steam** 意味着在容器里不用装 Steam 客户端；而那份 `dxgi.log` 说明你之前已经用**老版 Winlator / 老 Turnip 驱动**跑过，卡在 Vulkan 初始化——这是本文第 7 节要解决的问题。

## 2. 为什么"转 APK"是死路（三条硬原因）

1. **原生代码不能跨架构。**
   IL2CPP 把 C# 全部 AOT 编译成 **x86-64 机器码**塞进 `GameAssembly.dll`。APK 需要的是 `arm64-v8a/lib/*.so`，必须**由源码用 Android Build Target 重新编译**才能得到。没有任何"转换器"能把 x64 机器码翻译成 arm64 原生库（Box64 是运行时翻译，不是产出 APK）。

2. **没有可以重编译的工程。**
   包里只有 `global-metadata.dat`（类型/方法描述）和编译产物，**没有 `.cs`、没有 `Assembly-CSharp.dll`、没有 `.unity` 工程**。用 Il2CppDumper 能反出伪 C# 骨架，但那是不可编译的符号表，不是源码。

3. **资源带平台锁。**
   Addressables 目录里写死 `"m_buildTarget":"StandaloneWindows64"`，shader 是 D3D11 编译的字节码。安卓版必须是 `Android` 平台的 bundle + GLES/Vulkan shader。

**一句话**：真要出 APK，等于拿到 UnityEngine 工程和 C# 源码，在 Unity 里把 Build Target 切成 Android 重新出包——这是重新开发，不是"改编"。

## 3. 四条能真正在手机上玩的路线

| 路线 | 原理 | 难度 | 画质 / 帧率 | 是否改包 | 适合谁 |
|---|---|---|---|---|---|
| **A. Winlator 11.2** ⭐ | Wine + Box64 翻译 + Turnip 驱动跑 Windows 版 | 中 | 720p 30–60fps（骁龙 8 Gen2/3） | 否，复制文件夹即可 | 想手机上"原生"玩 |
| **B. 盖世游戏 GameHub** | 同类容器，傻瓜化 + 云游戏 | 低 | 同上，调优项少 | 否 | 不想折腾 |
| **C. 串流**（Sunshine + Moonlight） | 电脑渲染，手机当屏幕 | 低 | **最高**（原生画质，延迟 10–30ms） | 否 | 家里有这台 PC、同局域网 |
| **D. Mobox / Termux + Box64** | 命令行容器 | 高 | 中 | 否 | 折腾党 |
| ~~E. 解包重建 Unity 工程出 APK~~ | 需要源码 | 不可行 | — | 是 | 无 |

**推荐顺序：A → C → B。** A 是你要的"装到手机上"，C 是最省心且画质无损（毕竟这台电脑本来就跑得动）。

## 4. 路线 A：Winlator 实操（针对这个包）

### 4.1 手机门槛（达不到就别折腾了）

| 项目 | 最低 | 舒适 |
|---|---|---|
| 系统 | Android 8.0，arm64 | Android 12+ |
| GPU | Adreno 6xx（Vulkan 1.1） | **Adreno 7xx**（Turnip 支持最好） |
| 内存 | 8 GB | 12 GB+ |
| 存储 | 5 GB 空闲 | 8 GB |
| 芯片 | 骁龙 855+ | 骁龙 8 Gen 2 / 8 Gen 3 / 8 Elite |

> ⚠️ 天玑 + Mali GPU 能跑但兼容性差（Turnip 是给 Adreno 的），优先用 Adreno 机型；Mali 请改用 Vortek 驱动或走路线 B。

### 4.2 安装 Winlator

1. 下载 **Winlator 11.2**（最新正式版，2026-09，自带 Box64 0.4.4、Turnip 26.2）：
   <https://github.com/brunodev85/winlator/releases/tag/v11.2.0>
   资产名形如 `Winlator_11.2.apk`。
2. 手机允许"未知来源"安装。
3. 首次打开会解包 rootfs（约 1–2 GB），再按提示下载 Wine / 组件。**全程需要联网**，耐心等。

> 别用 7.x/8.x 老版本——你日志里那个 `DXVK 1.10.3-async` 就是老打包的产物，Vulkan 初始化失败很可能就是它害的。

### 4.3 新建容器（照这张表填）

打开 Winlator → `Containers` → `+` 新建，参数照抄：

| 设置项 | 值 | 原因 |
|---|---|---|
| Screen Size | **1280x720** | Unity 6 在 720p 下最稳；高了帧率崩 |
| Graphics Driver | **Turnip**（Adreno）/ Vortek（Mali） | Turnip 是 Adreno 专用 Vulkan |
| DX Wrapper | **DXVK** | D3D11 → Vulkan，Unity 必需 |
| DXVK Version | 默认（11.2 自带 2.x） | 不行再回退 2.3.1 |
| Audio Driver | ALSA | 延迟低 |
| Box64 Preset | **Stability (Unity)** | 官方文档对 Unity 游戏的明确建议 |
| Box64 Version | 0.4.4 | 随 11.2 |
| Force Fullscreen | 开 | 免得窗口错位 |

容器建好后进入 `Advanced` 页，确认 **Box64 preset = Stability**、勾上 **Force Fullscreen**。

### 4.4 把游戏放进手机

Winlator 的 `D:` 盘默认映射到手机的 `Download` 目录。所以：

```
手机内部存储/Download/PVZ Replanted/Replanted.exe
手机内部存储/Download/PVZ Replanted/Replanted_Data/...
```

用数据线把整个 `PVZ Replanted` 文件夹拖进去即可（或用我给的 zip 一次拷过去再解压，见第 8 节）。

### 4.5 建快捷方式 + 启动参数

1. Winlator 主界面 → `Shortcuts` → `+` → 浏览到 `D:\PVZ Replanted\Replanted.exe`。
2. 给它起名 `PvZ Replanted`，容器选刚建的那个。
3. 在快捷方式设置 → `Advanced` → **Exec Arguments** 填：

```
-force-d3d11 -force-gfx-direct -screen-width 1280 -screen-height 720
```

- `-force-d3d11`：强制走 D3D11，避开这个包里实验性的 D3D12（`D3D12/D3D12Core.dll`），Winlator 的 VKD3D 对 Unity 6 不稳。
- `-force-gfx-direct`：Unity 在 Wine 下卡死的经典解法。
- 分辨率参数防止它按桌面尺寸开窗。

也可以直接双击游戏目录里的 `Replanted_Android.bat`（我放在包里了），效果一样。

### 4.6 触摸怎么点

PvZ 是纯鼠标操作（点种子卡、点草坪）：

- Winlator 默认 **触摸 = 鼠标左键**，直接点就行。
- 在 `Input Controls` 里打开 **"Move Mouse when pressing button / 按下时移动鼠标"**，避免光标和手指错位。
- 想更顺手：蓝牙鼠标或手柄映射（Winlator 11 支持 XInput 手柄）。

### 4.7 第一次启动为什么"像卡死"

`GameAssembly.dll` 87 MB 的 x64 代码要在 ARM 上被 Box64 边翻译边执行，**首次进入主菜单 1–3 分钟很正常**。之后 Box64 会缓存，第二次快很多。别在 30 秒内就杀进程。

## 5. 路线 B：盖世游戏 GameHub（更省事）

不想碰容器参数就用它：

1. 装「盖世游戏」App（小鸡/GameHub，Android 版）。
2. 数据线把 `PVZ Replanted` 文件夹拖到手机。
3. App 里 `游戏库 → 添加游戏 → 选择 Replanted.exe`。
4. 它自带容器和驱动预设，启动更快；缺点是可调项少、部分版本要登录。

参考说明：<https://m.ithome.com/mip/html/827711.htm>

## 6. 路线 C：串流（画质天花板，零兼容风险）

家里有这台 PC 且同 Wi-Fi 时，这是**体验最好**的方案，手机端只是解码：

1. PC 装 **Sunshine**：<https://github.com/LizardByte/Sunshine>
2. 手机装 **Moonlight**（应用商店 / <https://moonlight-stream.org>）
3. PC 与手机同 5GHz Wi-Fi（最好有线连 PC），Moonlight 里添加 PC、选桌面或直接启动 `Replanted.exe`。
4. 手机接手柄或开屏幕触控即可。

1080p60 / 4K 都能跑，延迟 10–30ms，PvZ 这种游戏完全无感。

## 7. 故障排查（按优先级）

| 现象 | 原因 | 处理 |
|---|---|---|
| `DxvkInstance::createInstance: Failed to create Vulkan 1.1 instance`（你日志里这个） | 驱动没提供 Vulkan 1.1：老 Turnip / 选错驱动 / 设备不支持 | 换 Winlator 11.2 + **Turnip**；Mali 用 Vortek；确认 `GPUInfo` 里 Vulkan 版本 ≥1.1 |
| 黑屏后退出 | Unity 6 在 Wine 下的图形线程问题 | 加 `-force-gfx-direct`；Box64 预设改 **Stability**；DXVK 回退 2.3.1 |
| 卡在 Unity 启动画面 | Box64 翻译太慢 / 内存不足 | 等 3 分钟；关后台；内存 8G 以下必炸 |
| 进游戏花屏/贴图错 | Turnip 版本与 Adreno 不匹配 | 换 Turnip 版本（11.2 自带 26.2，可试 25.1） |
| 声音爆音/无声 | ALSA 缓冲 | 换 Audio Driver 为 PulseAudio / 调缓冲 |
| 点不准 | 光标未跟随触摸 | 开 "Move Mouse when pressing button" |
| 存档丢失 | 存档在 `C:\users\xuser\AppData\LocalLow\PopCap Games\PvZ Replanted` | 备份该目录；容器重装会丢 |
| 启动就报 Steam 相关错误 | 免 Steam 的 emu 未生效 | 确认 `Plugins\x86_64\steam_emu.ini` 在位；`AppId=1903340` |

## 9. 现实预期

- **能玩**：骁龙 8 Gen2/3 的机器，720p 下 30–60fps，触摸操作 OK。
- **不能玩**：中低端 Mali 机型、6 GB 内存、Android 8 以下——别浪费时间。
- **启动慢**：首启 1–3 分钟，之后 20–40 秒。
- **画质**：720p 拉伸到手机屏，UI 会偏小，可把容器分辨率调到 1600x900 换清晰度（帧率下降）。
- **这不是 APK**：手机桌面不会出现一个"PvZ Replanted"图标，而是 Winlator 里一个快捷方式。想要真图标，只能用路线 C 或等官方（无期）。
